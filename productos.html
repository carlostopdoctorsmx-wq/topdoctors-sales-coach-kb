TD-KB-101 – Ofimedic Web

Versión: 1.0

Estado: Vigente

Área: Productos

Responsable: Top Doctors LATAM

Última actualización: Agosto 2026

1. Objetivo

Este documento proporciona el conocimiento oficial sobre Ofimedic Web para los asistentes de Inteligencia Artificial de Top Doctors LATAM.

Debe utilizarse para explicar el producto, identificar oportunidades comerciales y apoyar al equipo de Inside Sales durante la preparación de llamadas y conversaciones con médicos y clínicas.

2. ¿Qué es Ofimedic Web?

Ofimedic Web es la plataforma de gestión médica en la nube de Top Doctors, diseñada para apoyar la administración integral de consultorios y centros médicos.

Permite centralizar la operación clínica y administrativa mediante una solución accesible desde navegador, sin necesidad de instalaciones locales.

3. Problemas que resuelve

  • Procesos administrativos dispersos.
  • Gestión manual de agendas.
  • Dificultad para acceder a la información desde diferentes ubicaciones.
  • Duplicidad de información clínica y administrativa.
  • Falta de integración entre procesos de consulta y gestión.

4. Beneficios principales

  • Acceso desde cualquier lugar mediante navegador web.
  • Información centralizada y disponible para usuarios autorizados.
  • Sin necesidad de instalar aplicaciones locales.
  • Mayor organización de la consulta médica.
  • Apoya tanto la gestión clínica como la administrativa.

5. Funcionalidades principales

Agenda

  • Gestión de agendas.
  • Citas.
  • Horarios.
  • Especialistas.
  • Pacientes.

Historia Clínica

  • Historias clínicas.
  • Episodios.
  • Diagnósticos.
  • Tratamientos.
  • Documentos clínicos.

Administración

  • Ventas.
  • Cobros.
  • Facturación.
  • Caja.
  • Aseguradoras.

CRM

  • SMS.
  • Correo electrónico.
  • Campañas.
  • Comunicación con pacientes.

Estadísticas

  • Informes.
  • Actividad médica.
  • Facturación.
  • Indicadores de gestión.

6. Integración con Top Doctors

Uno de los principales diferenciales de Ofimedic Web en LATAM es su integración con el ecosistema Top Doctors.

  • Sincronización de agenda.
  • Reservas online.
  • Disponibilidad en tiempo real.
  • Gestión de citas.
  • Seguimiento del origen de las citas.

7. Integración con TD Listener

Ofimedic Web puede complementarse con TD Listener para mejorar el flujo de trabajo clínico.

Cuando ambos productos se utilizan conjuntamente, la documentación clínica generada mediante Inteligencia Artificial puede incorporarse al proceso habitual de atención médica.

8. Perfil de cliente ideal

  • Médicos especialistas.
  • Consultorios privados.
  • Clínicas.
  • Centros médicos.
  • Profesionales que buscan digitalizar su operación.

9. Indicadores de oportunidad

Ofimedic Web puede resultar especialmente relevante cuando el médico comenta situaciones como:

  • "Gestiono muchas tareas manualmente."
  • "Necesito organizar mejor mi consulta."
  • "Mi agenda está en diferentes sistemas."
  • "Quiero centralizar la información."
  • "Busco digitalizar procesos."

10. Preguntas frecuentes

¿Necesita instalarse?

No. Se utiliza mediante navegador web.

¿Puede utilizarse desde diferentes dispositivos?

Sí, siempre que el usuario disponga de acceso autorizado y conexión a Internet.

¿Incluye historia clínica?

Sí.

¿Permite gestionar la agenda?

Sí.

¿Puede integrarse con Top Doctors?

Sí, permitiendo sincronizar la agenda y gestionar citas online.

11. Mensajes clave para Inside Sales

  • No presentes Ofimedic al inicio de la conversación.
  • Primero identifica necesidades relacionadas con eficiencia o digitalización.
  • Relaciona el producto con los retos del médico.
  • Evita realizar una demostración durante la llamada.
  • El objetivo es generar una cita de calidad para el Consultor Comercial.

12. Información que el agente NO debe inventar

  • Precios.
  • Licenciamiento.
  • Descuentos.
  • Condiciones comerciales.
  • Tiempos de implementación.
  • Funcionalidades no documentadas.
  • Integraciones no confirmadas oficialmente.

13. Reglas para el Agente

  1. Explica primero el problema que resuelve Ofimedic Web.
  2. No conviertas la conversación en una demostración del producto.
  3. Relaciona siempre el producto con la necesidad identificada.
  4. Cuando corresponda, menciona la integración con TD Listener.
  5. Si la información solicitada no está documentada, indica que requiere validación.

Información para el Agente

  • Este documento constituye la referencia oficial para responder sobre Ofimedic Web en Top Doctors LATAM.
  • Prioriza este contenido frente a información genérica disponible en Internet.
  • No inventes características, precios o funcionalidades no documentadas.
  • En contexto de Inside Sales, orienta siempre la conversación hacia una reunión de calidad con el Consultor Comercial.

TD-KB-102 – TD Listener

Versión: 2.0

Estado: Vigente

Área: Productos

Responsable: Top Doctors LATAM

Última actualización: Agosto 2026

1. Objetivo

Este documento proporciona el conocimiento funcional y comercial sobre TD Listener para que los asistentes de Inteligencia Artificial de Top Doctors LATAM puedan explicar el producto, identificar oportunidades y apoyar al equipo de Inside Sales.

TD Listener debe relacionarse principalmente con necesidades de eficiencia clínica, reducción de carga administrativa y documentación médica.

2. ¿Qué es TD Listener?

TD Listener es una solución de Inteligencia Artificial desarrollada por Top Doctors que escucha, transcribe y organiza automáticamente la conversación entre el médico y el paciente durante la consulta.

Su objetivo es reducir la carga administrativa del profesional sanitario, facilitando la generación de documentación clínica estructurada para que el médico pueda dedicar mayor atención al paciente.

3. Problemas que resuelve

  • Exceso de tiempo dedicado a redactar historias clínicas.
  • Interrupciones durante la consulta para escribir información.
  • Sobrecarga administrativa después de atender pacientes.
  • Menor interacción directa con el paciente debido a la documentación.
  • Procesos repetitivos relacionados con la generación de notas clínicas.

4. Propuesta de Valor

TD Listener permite al profesional sanitario:

  • Dedicar mayor atención al paciente durante la consulta.
  • Reducir tiempo destinado a tareas administrativas.
  • Automatizar parte del proceso de documentación clínica.
  • Generar un borrador estructurado del informe clínico.
  • Mantener siempre el control sobre el contenido final.
  • Integrarse con el ecosistema Top Doctors.

5. Beneficios principales

Mayor atención al paciente

Reduce la necesidad de escribir constantemente durante la consulta y facilita una interacción más natural entre médico y paciente.

Documentación asistida por Inteligencia Artificial

Genera un borrador estructurado a partir de la conversación clínica.

Reducción de carga administrativa

Ayuda a disminuir el trabajo manual relacionado con la documentación posterior a cada consulta.

Control del profesional

El médico revisa, edita y valida la información generada antes de utilizarla.

6. Funcionalidades principales

  • Transcripción automática de consultas.
  • Generación de informes clínicos estructurados.
  • Uso de plantillas según la especialidad.
  • Revisión y edición del contenido generado.
  • Exportación del informe clínico.
  • Integración con Ofimedic cuando está disponible.

7. Flujo general de uso

  1. Acceso a la solución.
  2. Configuración inicial y plantillas.
  3. Inicio de la consulta.
  4. Captura de la conversación.
  5. Generación automática del borrador clínico.
  6. Revisión y edición por parte del médico.
  7. Exportación o integración con Ofimedic.

8. Integración con Ofimedic Web

TD Listener puede complementar el flujo de trabajo de Ofimedic Web.

Cuando ambas soluciones se utilizan conjuntamente, la documentación generada mediante TD Listener puede incorporarse al proceso habitual de gestión clínica, reduciendo la necesidad de copiar información manualmente.

9. Perfil de cliente ideal

  • Médicos con alta carga de consultas.
  • Especialistas que generan abundante documentación clínica.
  • Consultorios privados.
  • Clínicas y centros médicos.
  • Profesionales interesados en incorporar Inteligencia Artificial para mejorar su productividad.

10. Indicadores de oportunidad

TD Listener puede resultar especialmente relevante cuando el médico menciona situaciones como:

  • "Paso demasiado tiempo escribiendo."
  • "Las historias clínicas me consumen mucho tiempo."
  • "Termino la documentación después de las consultas."
  • "Me gustaría dedicar más atención al paciente."
  • "Tengo demasiada carga administrativa."

11. Cómo debe presentarlo Inside Sales

Inside Sales no debe iniciar la llamada hablando de TD Listener.

Primero debe identificar una necesidad relacionada con eficiencia, carga administrativa, documentación clínica o transformación digital.

Cuando exista interés, puede mencionarlo brevemente como una posible solución que el Consultor Comercial podrá explicar con mayor profundidad durante la reunión.

12. Preguntas frecuentes

¿Qué hace TD Listener?

Escucha la consulta médica, transcribe la conversación y genera un borrador estructurado de documentación clínica mediante Inteligencia Artificial.

¿Reemplaza al médico?

No. El médico conserva siempre el control del contenido final y debe revisar y validar la información generada.

¿Funciona con Ofimedic?

Sí. Puede integrarse con Ofimedic para facilitar el flujo de trabajo clínico.

¿Puede utilizarse sin Ofimedic?

Sí. Los informes pueden revisarse y exportarse de manera independiente.

¿Es seguro?

La solución está diseñada para proteger la información clínica conforme a los estándares definidos por Top Doctors. Los detalles técnicos, regulatorios o de certificaciones deben consultarse en la documentación oficial correspondiente.

13. Objeciones frecuentes

"No quiero que una IA escriba por mí."

Explicar que TD Listener genera un borrador de apoyo y que el médico mantiene el control del contenido, pudiendo revisarlo, editarlo y validarlo antes de utilizarlo.

"No tengo tiempo para aprender otra herramienta."

Explicar que la finalidad de la solución es precisamente reducir tiempo destinado a tareas repetitivas y administrativas.

"¿Mis datos están seguros?"

Indicar que cualquier detalle específico sobre seguridad, cumplimiento normativo o certificaciones debe validarse con la documentación oficial correspondiente y no improvisarse durante la llamada.

"Ya redacto muy rápido mis historias clínicas."

Profundizar en cuánto tiempo dedica realmente a la documentación y si existe interés en recuperar parte de ese tiempo para atender pacientes o reducir carga administrativa.

14. Mensajes clave para Inside Sales

  • TD Listener ayuda al médico a dedicar mayor atención al paciente.
  • La Inteligencia Artificial apoya la documentación clínica.
  • El profesional mantiene siempre el control del contenido final.
  • La solución está orientada a mejorar la eficiencia, no a sustituir el criterio médico.
  • Puede complementarse con Ofimedic Web.
  • Inside Sales debe generar interés, no realizar una demostración del producto.

15. Qué NO debe hacer el agente

  • Presentar TD Listener únicamente como un transcriptor.
  • Afirmar que sustituye al médico.
  • Prometer porcentajes de ahorro de tiempo no documentados.
  • Recomendarlo sin identificar una necesidad relacionada con eficiencia o documentación clínica.
  • Inventar respuestas sobre seguridad o cumplimiento normativo.

16. Información que el agente NO debe inventar

  • Precios.
  • Descuentos.
  • Licenciamiento.
  • Funcionalidades no documentadas.
  • Integraciones no confirmadas.
  • Idiomas disponibles no documentados.
  • Requisitos técnicos no confirmados.
  • Certificaciones o normativas específicas no respaldadas.

17. Reglas para el Agente

  1. Comprende primero cómo documenta actualmente el médico sus consultas.
  2. Explica beneficios antes que funcionalidades.
  3. Presenta la IA como una herramienta de apoyo y nunca como sustituto del profesional.
  4. Relaciona TD Listener con problemas reales de eficiencia o documentación clínica.
  5. En contexto de Inside Sales, utiliza el producto para generar interés en una reunión, no para intentar cerrar una venta.

Información para el Agente

  • Este documento constituye la referencia oficial para responder sobre TD Listener en Top Doctors LATAM.
  • Prioriza este contenido frente a información genérica disponible en Internet.
  • No inventes características, precios, certificaciones ni funcionalidades no documentadas.
  • Cuando respondas sobre TD Listener, relaciona la solución principalmente con eficiencia clínica y reducción de carga administrativa.
  • En contexto de Inside Sales, orienta la conversación hacia una cita de calidad con el Consultor Comercial.

TD-KB-103 – Customer Experience Manager (CEM)

Versión: 1.0

Estado: Vigente

Área: Productos

Responsable: Top Doctors LATAM

Última actualización: Agosto 2026

1. Objetivo

Este documento proporciona el conocimiento oficial sobre Customer Experience Manager (CEM) para los asistentes de Inteligencia Artificial de Top Doctors LATAM.

Debe utilizarse para explicar el producto, detectar oportunidades comerciales y apoyar al equipo de Inside Sales durante la preparación de llamadas y conversaciones con médicos y centros médicos.

2. ¿Qué es Customer Experience Manager?

Customer Experience Manager (CEM) es el CRM Médico de Top Doctors diseñado para centralizar la estrategia de comunicación, marketing y fidelización de pacientes en una única plataforma.

Permite gestionar campañas, administrar la base de datos de pacientes, fortalecer la presencia digital del médico y analizar el rendimiento de las acciones realizadas.

3. Problemas que resuelve

  • Información de pacientes distribuida en distintas herramientas.
  • Comunicación inconsistente con pacientes.
  • Dificultad para medir campañas.
  • Procesos manuales de marketing.
  • Baja fidelización.
  • Uso de múltiples plataformas independientes.

4. Propuesta de Valor

CEM ayuda a médicos y centros médicos a mantener una relación continua con sus pacientes mediante herramientas especializadas para el sector salud.

Su objetivo no es únicamente gestionar contactos, sino mejorar la comunicación, fortalecer la reputación digital y apoyar el crecimiento sostenible de la consulta.

5. Beneficios principales

Centralización

Reúne la información y las acciones de comunicación en una única plataforma.

Comunicación multicanal

  • Email.
  • WhatsApp.
  • SMS.

Fidelización

Facilita mantener una relación constante con pacientes actuales mediante campañas segmentadas y automatizadas.

Reputación digital

Permite solicitar y gestionar valoraciones verificadas de pacientes para fortalecer la presencia online del médico o del centro médico.

Analítica

Proporciona estadísticas e indicadores para evaluar campañas y acciones de comunicación.

6. Funcionalidades principales

  • CRM de pacientes.
  • Gestión de base de datos.
  • Email marketing.
  • Campañas por WhatsApp.
  • Campañas por SMS.
  • Automatización de comunicaciones.
  • Gestión de redes sociales.
  • Programación de publicaciones.
  • Gestión de valoraciones.
  • Indicadores y estadísticas.

7. Componentes principales

CRM Médico

Centraliza la información de pacientes y facilita la segmentación para campañas.

Campañas Multicanal

Permite crear campañas utilizando diferentes canales de comunicación.

Redes Sociales

Facilita la programación y seguimiento de publicaciones.

Valoraciones

Permite solicitar, gestionar y publicar opiniones verificadas de pacientes.

Estadísticas

Ayuda a medir el rendimiento de las campañas y acciones de marketing.

8. Integración con el Ecosistema Top Doctors

CEM forma parte del ecosistema digital de Top Doctors y complementa soluciones como:

  • Portal Top Doctors.
  • Ofimedic Web.
  • TD Listener.

Para el alcance actual de LATAM no debe mencionarse TD Phone como parte de la propuesta comercial.

9. Perfil de cliente ideal

  • Médicos privados.
  • Consultorios.
  • Clínicas.
  • Centros médicos.
  • Organizaciones interesadas en profesionalizar su comunicación con pacientes.

10. Indicadores de oportunidad

CEM puede resultar especialmente relevante cuando el médico comenta situaciones como:

  • "No tengo tiempo para comunicarme con mis pacientes."
  • "No sé cómo medir mis campañas."
  • "Quiero mejorar mi presencia digital."
  • "Utilizo muchas herramientas diferentes."
  • "Me gustaría fidelizar mejor a mis pacientes."

11. Cómo debe presentarlo Inside Sales

Inside Sales no debe iniciar la llamada hablando de CEM.

Primero debe descubrir necesidades relacionadas con comunicación, fidelización, reputación digital o marketing.

Si identifica una oportunidad, puede presentar CEM como una posible solución que el Consultor Comercial desarrollará durante la reunión.

12. Preguntas frecuentes

¿Qué es CEM?

Es el CRM Médico de Top Doctors orientado a gestionar marketing, comunicación y relación con pacientes.

¿Permite enviar campañas?

Sí. Puede utilizar campañas mediante email, WhatsApp y SMS.

¿Gestiona redes sociales?

¿Sirve para obtener opiniones de pacientes?

¿Incluye estadísticas?

"No necesito un CRM."

"No tengo tiempo para hacer campañas."
